## Edge Cases

- **A push arrives while the page's own press is awaiting its answer**: render "Last checked" from the push; the result line waits for the answer.
- **The setting is turned off during a press**: main answers `failed` (aborted); the line shows "Couldn't check"; the notice clears from the push.
- **Two Settings pages**: each shows its own answer to its own press; both show the same "Last checked" from the push.
- **The chrome reloads (chrome recovery)**: the boot read re-applies the dot.
- **`canCheck` false in a dev build without the override**: the button disabled from the first state read.
- **`renderer.js` would need a line**: it must not — `[BLOCKED:renderer-budget]`.
