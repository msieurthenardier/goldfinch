- **Rig finding (rerun of checkpoint 1)**: under WSL2 **mirrored networking**

  the tab sat pending, census `ok`, no panel. `127.0.0.2` refuses at 0 ms.
  **Ruling**: substitute `127.0.0.2` for every `{P}`/`{Q}` URL for the run,
  bind the retry server to `127.0.0.2`; the TLS fixture stays on
  `127.0.0.1`. The first attempt is recorded as a rig finding, not a
  verdict. Spec preconditions revised accordingly.

  composite paints the hidden failed guest's blank `capturePage()` over the
  chrome panel (`grabWindow`'s fallback never consults guest visibility) —

## Closing Summaries

### Executor closing
Run went end to end with one rerun (step 1) caused by the rig, not the app.
Notes for the crew file: (1) WSL2 mirrored networking never refuses an
unbound 127.0.0.1 port — SYNs are dropped; `127.0.0.2`/`127.1.1.1`/`[::1]`
refuse at 0 ms, and `python3 -m http.server --bind 127.0.0.2` serves and
refuses cleanly after stop; the URL host must match the bind. (2)
`captureWindow` is not a faithful rendered observable for chrome-DOM panels
under Wayland: `grabWindow` paints the active guest's `capturePage()`
unconditionally, so a hidden failed guest is drawn white over the panel —
use `captureScreenshot(chromeWcId)` + the chrome a11y tree. (3) Transient
`captureWindow` "chrome window unavailable" ~0.5–1 s after a failure lands
or a tab activates; a 1.5 s retry succeeded every time; mid-connect it
times out on the guest capture instead. (4) `document.hasFocus()` is false
on the chrome document throughout — the app window is not the OS-focused
surface under automation on WSLg, so `:focus`/`:focus-visible` never match
and no ring paints; keyboard evidence is activeElement + a11y `focused`.
(5) `python3 -m http.server` with stdout redirected never flushes its banner
— gate readiness on `ss -ltn` + a curl 200 (or `python3 -u`). (6) Shell
gotcha: `cd … && VAR=… && nohup … &` backgrounds the whole chain. (7) App
observations: after a tool-driven `navigate` that fails, the address bar
keeps the previous URL while panel/strip/census carry the intended one; the
typed-Enter path updates it. Census `title` for a failed tab is inconsistent
('New tab' / stale / ''). The `navigate` tool returns the failure string as
an `isError` result. F6 demonstrably moves focus address bar → heading; Tab
reaches Retry in one press. Reopen honored the original strip index. The
timeout probe tab was disturbed by loopback diagnostics.
