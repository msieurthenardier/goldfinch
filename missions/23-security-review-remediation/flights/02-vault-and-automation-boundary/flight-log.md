### Electron 45 (documentation review)

- 45.0.0: Chromium 156, Node 24.22, V8 15.6 (from Chromium 152, Node 24.18). Latest 45 patch at planning: **45.3.2**; Dependabot's PR names 45.3.0. Latest 44 patch: 44.11.3.
- 45.3.2 fixes cookies set shortly before quit sometimes not being saved; 45.3.0 fixes unbounded `webRequest` redirect loops.
- Breaking changes listed for 45.0, each checked against this code by grep: sandboxed preloads lose the `events` / `timers` / `url` shims and the `Buffer` / `setImmediate` globals (not used in `src/preload/`; the bundled observer is checked live); `chrome-extension:` subframes no longer get preloads (the PDF viewer never relied on one); `window.open` children of unsandboxed windows are sandboxed separately (guest popups already set `sandbox: true`; the chrome denies all `window.open`); screen capture is reported as `display-capture` (denied either way); `requestStorageAccessFor` off by default; dummy `libEGL` / `libGLESv2` removed from the Linux distribution (packaging re-checked).
- Not verified from documentation: `node:sqlite` changes between Node 24.18 and 24.22; electron-builder 26.18 against Electron 45 beyond "no stated requirement"; the PR's mergeable state.
- Code and docs that name Electron 44 or 43 as the measured version: `CLAUDE.md` (crash reason note), `src/main/capture-failure.js`, `src/main/main.js` (crash directory note), `src/main/relaunch-options.js`, `src/main/session-runtime.js`, `test/unit/auth-challenges.test.js` comments, and several behavior specs' run notes.
