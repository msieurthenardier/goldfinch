## Critical gap outside this flight's surfaces

No critical gap outside this flight's surfaces was found.

The flight's divert example — a navigation-guard path from web content to `goldfinch://` — does not exist in the code as read. A web guest's `will-navigate`, `will-redirect` and `will-frame-navigate` all run `isSafeTabUrl` (scheme-only: `http:`, `https:`, `about:blank`), `goldfinch:` is served by a `protocol.handle` on the internal session alone, the renderer `createTab` gate and the main `tab-navigate` / `cert-override-proceed` / automation `navigate` gates each re-check, and the only unvalidated main-side loaders (`tab-create`, 22c) are chrome-sender channels. Rows N1–N9 below. The one gap that touches this surface is low severity and chrome-trust only (N8, finding 22c).

## Method and limits

- Surfaces and rows: navigation (N), permissions (P), popups and new windows (O), TLS trust (T), the 13 guest-preload channels (G). - Electron statements cite the installed typings (`node_modules/electron/electron.d.ts`, 44.10.0), not memory.
- Not covered by this audit (so absent from the tables): the PDF viewer extension's own behaviour once loaded, favicon fetching, the media proxy and download handlers (owned by the jar-isolation leg), the auth-challenge store beyond one adjacent row.

## Q6 — can `confirmedOrigins` be added without a vault file-format version bump?

**Verdict: no version bump needed.** An unknown non-secret field on a stored item survives every path that carries the item as a whole object, nothing throws on it at load, and the format version is not consulted for item shape. Two seams drop it and need explicit code (neither is a format change): the vault-page editor's save and the metadata projection, exactly as `matchMode` already is.

**Deciding citations.**
- Items are one opaque AES-GCM JSON blob per vault; `parseVault` (`main/vault/vault-crypto.js:701`) validates only the envelope (format id, `version === VERSION`, kdf, envelopes, items blob shape) and never looks inside; `decryptItems` (`:264`) is `JSON.parse` of the plaintext. AAD is `gfvault/items/<version>` (`:168`) and carries no item shape, so adding a field changes no authenticated header.
- The only per-item validators check `type` and `id` and nothing else: `validateImportedItems` (`main/vault/vault-store.js:550`) and `partitionImportedItems` (`:591`; drops unknown TYPES, keeps whole objects), both on bundle paths; `_normalizeItem` (`:3002`) is `{...item, id, type, createdAt, updatedAt}` — a spread, so unknown fields pass through every write.
- `SCHEMA` (`shared/vault-item-schema.js:46`) drives `metadataOf` (`:103`, a positive whitelist: an unknown key never leaves the main process via the metadata projection) and `secretFieldsFor`. Adding `confirmedOrigins` to `SCHEMA.*.nonSecret` would trip the layout-to-schema drift guard (`test/unit/vault-editor-model.test.js:17-22`, which pins `nonSecretNames` equal to `SCHEMA` and so would also render a text input). It must follow the `matchMode` precedent instead: a bespoke derived flag in `metadataOf` (`vault-item-schema.js:103-114`).

## Q7 — popups as guest senders

**Method.** The census's guest-channel enumeration (13 channels, `ipc-census.md`). A popup is a `BrowserWindow` created by the allow path of `setWindowOpenHandler` (O1) with the web-guest `webPreferences`, so it runs the same `webview-preload` and can send every one of the 13. The relevant resolver facts, all read:

- `registry.getWindowForGuest(wcId)` (`main/window-registry.js:205`) scans each record's `tabViews`; popups are never in `tabViews` (`popup-registry.js` header, and `guest-wiring.js:364-365` registers them only in the popup registry), so it returns `null` for a popup sender. `getChromeForTab(wcId)` (`:219`) is built on it, so `chromeForTab(popup)` is `null` and every `chromeForTab(wcId)?.send(...)` push is a no-op for a popup.

The only window a popup maps to is `popupEntry.openerRecord`, whose `activeTabWcId` is the opener WINDOW's active tab — not the popup and not necessarily the opener's own tab. No handler reads that value for a popup today.
