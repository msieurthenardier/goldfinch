# v0.19.17 — A dot on the menu when an update is waiting, and a Check now button

This release makes the update notice easier to see and lets you check for a new version on demand.

## Added

- **A dot on the ⋯ menu button while a newer release is known.** It appears and clears without a restart, in every open window. Seen in two windows in a test run, and on Windows on a release candidate.
- **A Check now button in Settings → About.** It asks GitHub once, even when automatic checks are turned off, and shows a short result: checking, a newer version found, up to date, or could not check. A second press within about 30 seconds is answered without asking GitHub again. Beside it, About shows when the last check ran.

## Fixed

- **"Download now" now has a screen-reader name that contains its visible words.** It was found by an accessibility audit.

## Notes

- Checked on Windows on a release candidate. Not checked on installed macOS or Linux builds.
- What Goldfinch sends and believes about releases is unchanged from the previous version.
