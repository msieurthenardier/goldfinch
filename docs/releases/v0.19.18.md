# v0.19.18 — Release notes you can read

Each release page now opens with notes written for the people using Goldfinch, instead of a list of merged changes.

## Changed

- **Release notes you can read.** From this release on, every release page — the one Goldfinch's update notice links to — says what changed, and what to do first when there is something to do before upgrading. The pages for v0.19.15, v0.19.16 and v0.19.17 have been rewritten the same way; v0.19.15's carries the warning about the vault file conversion.
- **A release candidate's page says so.** Its title carries the candidate's tag, and its notes open with a line saying it is for testing, not general use.

## Notes

- Nothing in the app itself changed. Your settings, vaults and data are untouched.
- Releases before v0.19.15 keep their original pages.
